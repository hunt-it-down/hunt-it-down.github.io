01ABOUT / 关于

一个以工程为起点，
但兴趣不止于工程的人。

我有计算机科学与技术的学习背景，目前从事航空数据相关的软件开发。日常工作涉及 Java / Spring Boot、Oracle、SQLite，以及多期结构化数据的比对、迁移和校验。

比起技术名词本身，我更在意它们为何这样设计：索引如何改变查询成本，数据如何在版本之间保持一致，模型的推理与外部记忆又是怎样协作的。

这个网站既是一份可以对外介绍自己的档案，也是一处缓慢更新的记录。不是所有探索都有结论；有些问题值得先保留下来。
